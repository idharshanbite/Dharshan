# Northstar React site

A responsive React landing page, ready for GitHub Pages.

## Run it locally

1. Install Node.js 22 or later.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the address shown.

## Publish it on GitHub Pages

1. Create an empty GitHub repository and upload these files to its `main` branch.
2. On GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main`. The included workflow builds and deploys the site automatically.
4. After the workflow completes, GitHub shows the public site URL in the workflow summary and in **Settings → Pages**.

Update the studio name, email address, and text in `src/main.jsx` to make the site yours.
